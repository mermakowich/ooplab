# Лабораторная работа №9 — Доска объявлений (UDP multicast)

## Цель

Познакомиться с сетевым программированием на C#: UDP-сокеты, multicast-рассылка, работа с фоновыми потоками в Windows Forms.

---

## Теория

### TCP и UDP

В сети программы общаются по двум основным протоколам прикладного уровня:

| | TCP | UDP |
|---|---|---|
| Установка соединения | Да | Нет |
| Гарантия доставки | Да | Нет |
| Порядок пакетов | Гарантирован | Не гарантирован |
| Скорость | Медленнее | Быстрее |
| Применение | Веб, почта, файлы | Игры, рассылки |

В лабе используется **UDP** — он быстрый и подходит для рассылок «один-многим».

### Сокеты и порты

**Сокет** — программный интерфейс ОС для работы с сетью. Через сокет программа отправляет и принимает пакеты.

**Порт** — числовой идентификатор (0–65535), по которому ОС определяет, какой программе адресован входящий пакет. В этой работе используется порт **8001**.

В C# для UDP есть удобный класс-обёртка `UdpClient` из пространства имён `System.Net.Sockets`.

### Режимы адресации в UDP

- **Unicast** — одному получателю (по его IP).
- **Broadcast** — всем в локальной сети (адрес `255.255.255.255`).
- **Multicast** — группе подписчиков. Адреса групп лежат в диапазоне `224.0.0.0 – 239.255.255.255`. Пакет получают только те, кто явно вступил в группу через `JoinMulticastGroup()`.

В работе используется multicast-адрес **`235.5.5.1`**.

Параметр **TTL** (Time To Live) определяет, через сколько маршрутизаторов может пройти пакет. В работе TTL = 20.

### Кодировка строк

По сети передаются только байты. Перед отправкой строка преобразуется в байты, после приёма — обратно:

```csharp
byte[] data = Encoding.Unicode.GetBytes("текст");   // строка → байты
string text = Encoding.Unicode.GetString(data);     // байты → строка
```

### Структурированные сообщения

Чтобы передать несколько полей в одном пакете, они склеиваются через разделитель `'|'`, а на стороне получателя разбираются методом `Split('|')`. Первое поле — тип сообщения, чтобы получатель сразу понимал, что пришло.

Протокол сообщений лабы:

| Тип | Формат | Пример |
|---|---|---|
| Объявление | `AD\|имя\|заголовок\|цена` | `AD\|Иван\|Велосипед\|3000` |
| Системное | `SYS\|текст` | `SYS\|Мария вошла на доску` |

Символ `'|'` выбран потому, что он почти не встречается в обычных текстах, в отличие от пробела или запятой.

### Фоновые потоки в Windows Forms

Метод `client.Receive()` — **блокирующий**: он останавливает выполнение до прихода пакета. Если вызвать его в главном потоке формы — окно зависнет. Поэтому приём запускается в фоновом потоке:

```csharp
Task.Run((Action)ReceiveMessages);
```

Но в Windows Forms есть правило: **изменять элементы формы можно только из главного потока**. Чтобы из фонового потока добавить запись в `ListBox`, используется `Invoke()`:

```csharp
this.Invoke(new MethodInvoker(() =>
{
    adsListBox.Items.Insert(0, display);
}));
```

### ObjectDisposedException при закрытии

При выходе вызывается `client.Close()`, и фоновый поток получает `ObjectDisposedException` в `Receive()`. Это штатная ситуация. Чтобы отличить её от настоящей ошибки, перед закрытием сокета флаг `alive` устанавливается в `false`. Если поток ловит исключение и видит `alive == false` — выходит тихо.

## Как работает программа

### Подключение (кнопка «Войти»)

```csharp
Socket socket = new Socket(AddressFamily.InterNetwork,
                           SocketType.Dgram,
                           ProtocolType.Udp);
socket.SetSocketOption(SocketOptionLevel.Socket,
                       SocketOptionName.ReuseAddress, true);
socket.Bind(new IPEndPoint(IPAddress.Any, PORT));

client = new UdpClient { Client = socket };
client.JoinMulticastGroup(groupAddress, TTL);

alive = true;
Task.Run((Action)ReceiveMessages);
SendPacket("SYS|" + userName + " вошёл на доску объявлений");
```

`ReuseAddress` нужен, чтобы можно было запустить **несколько экземпляров программы на одной машине** — все они смогут привязаться к порту 8001 одновременно. После вступления в группу запускается фоновый поток приёма и рассылается системное сообщение о входе.

### Публикация (кнопка «Опубликовать»)

```csharp
string packed = string.Join("|", "AD", userName, title, price);
byte[] data = Encoding.Unicode.GetBytes(packed);
client.Send(data, data.Length, HOST, PORT);
```

Поля упаковываются через `'|'`, кодируются в байты и рассылаются всем участникам multicast-группы.

### Приём (фоновый поток)

```csharp
while (alive)
{
    IPEndPoint remoteIp = null;
    byte[] data   = client.Receive(ref remoteIp);
    string packed = Encoding.Unicode.GetString(data);
    string[] parts = packed.Split('|');

    if (parts[0] == "AD") { /* формируем строку объявления */ }
    else if (parts[0] == "SYS") { /* формируем системную строку */ }

    this.Invoke(new MethodInvoker(() => adsListBox.Items.Insert(0, display)));
}
```

Цикл ждёт пакет, разбирает его по типу и через `Invoke` добавляет в список. Новые сообщения вставляются в начало списка (индекс 0).

### Выход (кнопка «Выйти» и закрытие формы)

```csharp
SendPacket("SYS|" + userName + " покинул доску объявлений");
alive = false;
client.DropMulticastGroup(groupAddress);
client.Close();
```

Сначала рассылается уведомление о выходе (пока сокет ещё открыт), затем устанавливается `alive = false`, программа покидает группу и закрывает сокет. Фоновый поток получает `ObjectDisposedException`, видит `alive == false` и завершается.

### Блокировка кнопок

- До входа: доступны `userNameTextBox` и `loginButton`; `publishButton` и `logoutButton` — заблокированы.
- После входа: наоборот.

## Порядок запуска

1. Открыть `Lab9.sln` в Visual Studio 2022.
2. Собрать проект (`Ctrl+Shift+B`).
3. Запустить **два** экземпляра `Lab9.exe` из папки `bin\Debug\` (двойным щелчком).
4. В каждом окне ввести имя и нажать «Войти» — в другом окне появится `→ имя вошёл на доску объявлений`.
5. Опубликовать объявление в одном окне — оно появится в обоих списках.
6. Нажать «Выйти» — оба окна увидят уведомление о выходе.
