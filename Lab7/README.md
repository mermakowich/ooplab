# Лабораторная работа №7 — Уровень 1

## Тема: Крестики-нолики (поле 3×3), Windows Forms, .NET Framework 4.7.2

---

## Что реализовано (все требования уровня 1)

- Игра двух игроков (человек vs человек) со счётом.
- Состояние поля — двумерный массив `int[3, 3]`: 0 = пусто, 1 = X, 2 = O.
- Три исхода: победа Игрока 1, победа Игрока 2, ничья.
- `MessageBox` по окончании раунда с именем победителя или «Ничья».
- Выигрышная комбинация зачёркивается чёрной линией поверх фигур.
- Кнопки «Новая игра» и «Сбросить счёт» под полем, а также через меню «Игра».
- Вся отрисовка — в обработчике события `Paint`.
- Координаты клика определяются через `MouseClick` (свойства `e.X`, `e.Y`).

## Как работает код

### Переменные (`Form1.cs`)

```
const int N    = 3;      // размер поля
const int CELL = 150;    // размер одной клетки в пикселях
int x0 = 50, y0 = 90;   // начало поля на форме
int[,] table = new int[N, N]; // 0=пусто, 1=X, 2=O
int hod;                 // номер текущего хода (0..8)
int win;                 // 0=игра идёт, 1=X, 2=O победил
int score1, score2;      // счёт раундов
int winx0, winy0, winx1, winy1; // концы выигрышной линии
```

### MouseClick — определение клетки
Клик `(e.X, e.Y)` — в координатах формы. Вычитаем `(x0, y0)` — получаем координаты внутри поля. Делим на `CELL = 150` — получаем индекс столбца (`col`) и строки (`row`):
```csharp
int col = (e.X - x0) / CELL;
int row = (e.Y - y0) / CELL;
```
Первый индекс в `table[col, row]` — столбец (X-направление), второй — строка (Y-направление). Чётный ход (0,2,4,...) → X (игрок 1), нечётный → O (игрок 2).

### CheckWin — проверка всех 8 комбинаций
- 3 строки: `table[0,j] == table[1,j] == table[2,j]` для j=0,1,2.
- 3 столбца: `table[i,0] == table[i,1] == table[i,2]` для i=0,1,2.
- Главная диагональ: `table[0,0] == table[1,1] == table[2,2]`.
- Побочная диагональ: `table[2,0] == table[1,1] == table[0,2]`.

При победе вызывается `SetWin(player, x0, y0, x1, y1)` — запоминает победителя и координаты линии в системе координат поля, увеличивает счёт.

### Paint — вся отрисовка
1. `g.TranslateTransform(x0, y0)` — сдвигаем начало координат к левому верхнему углу поля. После этого все координаты отсчитываются от угла поля.
2. Рисуем рамку и сетку (`DrawRectangle`, `DrawLine`).
3. Цикл по всем клеткам: `table[i,j]==1` → рисуем два `DrawLine` (крестик, красный); `table[i,j]==2` → `DrawEllipse` (нолик, синий).
4. Если `win != 0` — рисуем чёрную линию `winx0,winy0 → winx1,winy1`.
5. Обновляем `labelScore1.Text` и `labelScore2.Text`.
6. Подсвечиваем `LightGreen` того, кто ходит следующим.

### Invalidate()
Вызывает перерисовку формы — после него Windows встанет в очередь вызов `Paint`. `MessageBox.Show()` создаёт свой цикл сообщений, который успевает обработать отложенный `WM_PAINT`, поэтому выигрышная линия отображается до появления диалога.

### Кнопки
- **Новая игра** → `StartNew()`: сбрасывает `win`, `hod`, очищает `table`, вызывает `Invalidate()`. Счёт не трогает.
- **Сбросить счёт** → `ResetAll()`: обнуляет `score1`, `score2` и вызывает `StartNew()`.

## Как запустить

1. Открыть `Lab7.sln` в Visual Studio 2022.
2. Платформа — .NET Framework 4.7.2 (уже в `.csproj`).
3. F5 → игра запустится по центру экрана.
4. Кликать мышью по клеткам — X ходит первым (красные крестики), O вторым (синие нолики). При победе или ничье появится `MessageBox` и нарисуется зачёркивающая линия.
