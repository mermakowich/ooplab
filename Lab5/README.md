## Краткая теория

### Наследование
Наследование — один из основных механизмов ООП. Производный класс получает все поля, свойства и методы базового класса (кроме конструкторов). Синтаксис в C#:

```csharp
public class Производный : Базовый { ... }
```

В C# поддерживается только одиночное наследование классов (от одного базового класса), но можно реализовывать несколько интерфейсов.

Конструктор производного класса вызывает конструктор базового через `base(...)`:

```csharp
public MyRectangle(...) : base(x, y, color, thickness) { ... }
```

### Полиморфизм
Полиморфизм позволяет работать с объектами разных производных классов через ссылку на базовый класс. Для этого в базовом классе метод объявляется ключевым словом `virtual`, а в наследниках — переопределяется через `override`.

```csharp
public virtual void Draw(Graphics g) { }      // в базовом
public override void Draw(Graphics g) { ... } // в наследнике
```

Во время выполнения CLR смотрит на реальный тип объекта и вызывает нужную версию метода. Благодаря этому можно хранить все фигуры в одном списке `List<GeometricFigure>` и вызывать `f.Draw(g)` — для каждого объекта вызовется его собственная реализация.

### Ключевые слова
- `virtual` — метод можно переопределять в наследниках.
- `override` — переопределение виртуального метода.
- `base` — обращение к членам базового класса.
- `abstract` — метод без реализации (наследник обязан переопределить).
- `sealed` — запрещает дальнейшее наследование/переопределение.

## Задание

Создать базовый класс «Геометрическая фигура» (поля: центр, цвет, толщина контура; метод замены цвета) и два класса-наследника — «Прямоугольник» и «Круг». Каждый наследник умеет: отрисовываться, считать площадь, проверять принадлежность точки. На форме рисуется несколько случайных фигур; при клике по фигуре её контур утолщается, цвет меняется на случайный, а в текстовое поле выводятся название и площадь.

## Как работает код

### `GeometricFigure.cs` — базовый класс
Содержит общие для всех фигур поля:
- `X`, `Y` — координаты центра;
- `FigureColor` — цвет;
- `LineThickness` — толщина контура.

Метод `ChangeColor(Color)` меняет цвет фигуры. Также объявлены виртуальные методы `Draw`, `GetArea`, `ContainsPoint` и свойство `Name` — они переопределяются в наследниках.

### `MyRectangle.cs` — прямоугольник
Добавляет поля `Width` и `Height`. Конструктор принимает все параметры (унаследованные + свои) и передаёт первую часть в `base(...)`.

- `Draw` — рисует прямоугольник через `Graphics.DrawRectangle`. Центр фигуры — `(X, Y)`, поэтому верхний левый угол вычисляется как `(X - Width/2, Y - Height/2)`.
- `GetArea` — `Width * Height`.
- `ContainsPoint` — проверка попадания точки в прямоугольник по координатам границ.

### `MyCircle.cs` — круг
Добавляет поле `Radius`.

- `Draw` — рисует окружность через `Graphics.DrawEllipse`.
- `GetArea` — `π * R²`.
- `ContainsPoint` — точка принадлежит кругу, если расстояние от неё до центра не больше радиуса. Проверяется по формуле `dx² + dy² ≤ R²` (без `Math.Sqrt`, чтобы быстрее).

### `Form1.cs` — главная форма
Хранит список фигур `List<GeometricFigure> figures` — именно базового типа, поэтому туда складываются и прямоугольники, и круги.

- **`CreateFigures()`** — в конструкторе создаёт 5 прямоугольников и 5 кругов со случайными размерами, координатами и цветом. Объект `Random rnd` используется для генерации случайных значений.
- **`panelDraw_Paint`** — обработчик отрисовки панели. В цикле `foreach` для каждой фигуры вызывается `f.Draw(e.Graphics)`. Это и есть полиморфизм: на этапе компиляции тип `f` — `GeometricFigure`, но во время выполнения вызывается `Draw` нужного наследника.
- **`panelDraw_MouseClick`** — при клике мышью проходим по списку с конца (чтобы выбрать «верхнюю» фигуру) и проверяем `ContainsPoint(e.X, e.Y)`. Для найденной фигуры:
  - увеличиваем толщину контура на 2;
  - вызываем `ChangeColor` со случайным цветом;
  - выводим в `textBoxInfo` название и площадь;
  - вызываем `panelDraw.Invalidate()` — это заставляет панель перерисоваться.

### `Program.cs`
Стандартная точка входа WinForms-приложения — запускает `Form1`.

## Как запустить

1. Открыть `Lab5.sln` в Visual Studio 2022.
2. Убедиться, что целевая платформа — .NET Framework 4.7.2 (она уже прописана в `.csproj`).
3. Нажать F5 (или «Запуск»).
4. На белой панели появятся фигуры. Клик по фигуре — её контур станет толще, цвет изменится, внизу появится надпись с названием и площадью.
